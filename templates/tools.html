Tools

Handy utilities for PlayStation Consoles.

Title ID Lookup

Search 67,000+ PlayStation titles by game name or title ID (CUSA/PPSA).

PS5 Update Lookup

Look up the latest update for a PS5 title from its version XML or _sc.pkg URL — version, system req, size, pkg URL.

Filesystem Browser

Search PS4 and PS5 filesystem paths — find files, directories, and system binaries.

param.sfo Viewer

Drop a param.sfo or zip to view all fields — title, ID, category, version, and more. Client-side only.

Function Lookup

Search 18,000+ Sony system functions from PS5 libraries — find which SPRX contains any sce* function.

Entitlement Dumper

Drop your entitlement.db to extract game titles, IDs, and package URLs. Parsed in-browser, URLs contributed to shared database.

Syscall Reference

Browse PS4 and PS5 system calls — search by name or number. 600+ PS4 and 700+ PS5 syscalls.

Error Code Lookup

Search 27,000+ PS4 and PS5 error codes — CE-number, hex, SCE_ constant, or description.

Patch Save ↗

Apply cheats and patches to a decrypted PS4/PS5 save with Apollo Patcher — browser-based tool by bucanero. Opens in a new tab.

Save Decrypters ↗

Decrypt and encrypt game saves in-browser — supports dozens of PS4/PS5 titles. By bucanero. Opens in a new tab.
